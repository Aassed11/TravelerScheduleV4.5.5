# TRAVELER Schedule V3.6

V3.5 기반 홈 화면 위젯 버전입니다.

## 추가 기능

### 1) TRAVELER 월간 캘린더 위젯
- 홈 화면에서 월간 달력 확인
- 일정이 있는 날짜 아래 `국가·지역` 표시
- 일정 상태에 따라 국가·지역 글자색 구분
- 오늘 날짜 강조
- 이전 달 / 다음 달 / 오늘 이동
- 날짜 터치 시 앱의 해당 날짜로 바로 이동
  - 일정이 있으면 해당 날짜 일정 요약 팝업
  - 일정이 없으면 해당 날짜로 새 여행 일정 등록창

### 2) TRAVELER 다가오는 일정 위젯
- 오늘 이후 진행/출발 예정 일정 최대 5건 표시
- 출발일, 행사명, 국가·지역, 상태 표시
- 일정 터치 시 해당 일정 상세 화면으로 바로 이동
- 새로고침 버튼 제공

### 3) 자동 위젯 갱신
- 앱에서 일정 추가 / 수정 / 삭제 시 위젯 갱신 요청
- 위젯 자체는 시스템 주기 갱신도 사용

## 버전
- versionCode: 9
- versionName: 3.6

## 삼성 갤럭시에서 위젯 추가
1. 홈 화면 빈 곳을 길게 누릅니다.
2. `위젯`을 선택합니다.
3. `TRAVELER 일정관리`를 찾습니다.
4. `TRAVELER 월간 캘린더` 또는 `TRAVELER 다가오는 일정`을 선택합니다.
5. 홈 화면에 배치한 뒤 크기를 조절합니다.
