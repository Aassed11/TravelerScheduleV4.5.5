# TRAVELER Schedule v3.2

여행사 실무용 Android 일정/업무관리 앱입니다. 기존 v2와 같은 applicationId(`com.traveler.schedule`)를 사용하며 versionCode 5으로 업데이트 설치할 수 있습니다.

## V3 주요 기능
- 일정 등록 강화: 행사명, 단체명, 국가·지역, 출발/귀국일, 인원, 담당자, 항공편, 호텔, 현지가이드, 차량, 여행사/랜드사, 고객 연락처, 메모, 상태
- 일정 상태: 견적 / 예약 / 확정 / 진행중 / 완료 / 취소
- 월간 달력: 행사 기간 표시, 상태별 색상 막대, 오늘 강조, 날짜별 일정 목록
- 주간 / 목록 보기 전환
- 행사 생성 시 12개 기본 업무 체크리스트 자동 생성
- 출발 D-30 / D-14 / D-7 / D-3 / D-1 자동 알림
- 항공권 발권 / 호텔 취소 / 잔금 지급 / 여권 확인일 기한 알림
- 홈 화면의 업무 대시보드 팝업: 진행 행사, 7일 이내 업무, 기한 초과 업무
- 기존 v2 DB를 v3 스키마로 Migration하여 기존 일정 데이터 보존

## GitHub Actions APK 빌드
저장소 루트에 이 프로젝트 내용을 업로드한 뒤 Actions의 `Build Android APK`가 자동 실행됩니다.
성공 후 Artifacts에서 `TravelerSchedule-V3.2-debug-apk`를 내려받아 `app-debug.apk`를 설치하세요.

## 빌드 기준
- Java 17
- Gradle 8.9
- Android Gradle Plugin 8.7.3
- Kotlin 2.1.20
- compileSdk / targetSdk 35


## V3.1 캘린더 날짜 팝업 개선
- 캘린더에서 날짜를 누르면 해당 날짜 일정이 있는 경우 요약 팝업 표시
- 요약 팝업에서 일정 상세 화면으로 바로 이동 가능
- 같은 날짜에 새 일정을 추가할 수 있는 `일정 추가` 버튼 제공
- 해당 날짜에 일정이 하나도 없으면 새 일정 등록창을 즉시 열고 출발일/귀국일을 선택 날짜로 자동 입력
- 월간 보기와 주간 보기 모두 동일한 날짜 클릭 동작 적용


## V3.2 사용성 개선
- 월간 캘린더에서 일정이 있는 날짜에 상태 색상 막대와 함께 `국가·지역` 값을 작은 글씨로 표시
- 휴대폰 시스템 뒤로가기 지원: 상세/팝업/하위 탭은 이전 단계로 이동, 홈에서만 종료 확인 팝업 표시
- 새 여행 일정 등록창에서 `일정 상태` 아래의 항공편~여권 확인 항목을 `상세 정보 및 주요 기한 ▼` 영역으로 접어서 표시
- 상세 입력 영역은 필요할 때만 펼쳐 입력 가능
