# TRAVELER Schedule V4.5.2 — 알림 간소화

알림 대상은 아래 3개 업무로 제한합니다.
- 항공 발권
- 호텔 확정
- APIS 입력

변경사항
- 출발 D-30/14/7/3/1 알림 제거
- 항공권 발권 시한/호텔 취소/잔금/여권 확인 개별 알림 제거
- 차량 예약, 가이드 확정, 보험 가입, 공문 발송, 명찰/현수막, 인보이스, 잔금, 최종 명단 등 나머지 체크리스트 알림 제거

- 설정 화면을 3개 중요 업무 알림 중심으로 단순화
- 알림 시간 설정 / 알림 테스트 기능은 유지
