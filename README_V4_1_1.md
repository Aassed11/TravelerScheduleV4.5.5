# TRAVELER Schedule V4.1.1

## Calendar month/year picker
- Tap the centered `yyyy년 M월` title in the Calendar tab.
- A year/month selection dialog opens.
- Change the year with left/right arrows.
- Choose one of the 12 months.
- Tap `이동` to jump directly to the selected month.
- `이번 달로 이동` quickly resets the picker to the current year/month.
- Existing previous/next month arrows and Today button are preserved.
