# TRAVELER Schedule V4.3.1 — 알림 보강 패치

추가/수정
- 직접 추가한 업무도 기한 알림 등록
- 업무 완료 시 해당 업무 알림 자동 취소
- 업무를 미완료로 되돌리면 기한 알림 재등록
- 업무 삭제 시 해당 알림 취소
- 일정 삭제 시 출발/주요기한/업무 알림 전체 취소
- 로그아웃으로 로컬 데이터를 비울 때 기존 예약 알림도 정리
- 주요 기한 날짜를 지우면 이전에 예약된 알림도 취소
- 설정 > 알림 시간 변경 기능 추가 (기본 09:00)
- 설정 > 알림 테스트 버튼 추가 (약 3초 후)
- 오늘 날짜인데 설정 시간이 이미 지났다면 약 5초 후 알림
- 기존 일정/체크리스트도 앱 실행 시 알림 예약 상태 재정비
