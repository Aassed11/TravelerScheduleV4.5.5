# TRAVELER Schedule V4.2.0

변경 사항
1. 환율 API를 5분 단위 갱신 소스로 변경하고 API의 실제 기준시각을 표시.
2. 환율을 홈 카드에서 제거하고 모든 메인 화면/일정 상세에서 열 수 있는 왼쪽 환율 사이드 패널로 이동.
3. 일정 상세 > 업무 직접 추가의 기한을 달력 팝업으로 선택.
4. 홈 > 오늘의 업무를 행사별 카드(레이어)로 묶어서 구분.
5. 별도 검색 탭을 제거하고 일정 탭 상단에 일정 검색을 통합.
6. 기존 검색 탭을 주소록으로 변경. 휴대폰 연락처 권한 후 전화/문자/카카오톡 연결.
   - 전화: 전화 앱 다이얼 화면
   - 문자: 해당 번호 문자 작성 화면
   - 카카오톡: Android 연락처만으로 특정 카카오 친구를 자동 지정할 수 없어 카카오톡 공유 화면으로 연결.

버전
- versionCode 20
- versionName 4.2.0

추가 권한
- android.permission.READ_CONTACTS

주의
- 환율은 시장 참고용이며 은행 현찰/송금 환율과 다를 수 있습니다.
- 카카오톡 특정 친구 직접 채팅 연결은 전화번호만으로는 공식 지원되지 않습니다.
