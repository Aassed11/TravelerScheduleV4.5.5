# TRAVELER Schedule V4.5.1

수정 사항
1. 앱 잠금(PIN/지문) 해제 시 Firebase 로그인 세션을 그대로 유지하도록 인증 초기화 순서 및 AuthStateListener 보강.
2. 주소록 연락처 액션에서 카카오톡 버튼/안내 문구 완전 제거. 전화/문자만 유지.
3. 홈 배너를 사실상 무한 Pager로 변경하여 3번째 배너에서 오른쪽으로 스와이프하면 1번째 배너로 자연스럽게 이어짐.
4. 새 여행 일정 필수 항목 표시 통일:
   - 행사명 *
   - 단체명 여행사 *
   - 국가·지역 *
   - 출발일 *
   - 귀국일 *
   필수값 미입력 시 저장 불가 및 필수 안내 표시.
5. 홈 > 업무 요약의 '대시보드'는 예약/확정/진행중 일정만 간결하게 보여주는 별도 예약 일정 요약 팝업으로 분리.
   상단 '업무 현황' 및 빠른 실행의 '업무 현황'은 기존 기간별 업무 대시보드 유지.
