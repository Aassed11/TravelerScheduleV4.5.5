# TRAVELER Schedule V3.8

V3.7 기반 업무관리 강화 버전입니다.

## 추가 기능
- 일정 상세 상단 별표로 중요 일정 즐겨찾기/해제
- 홈 화면에 중요 일정 최대 3건 표시
- 일정 목록에서 즐겨찾기 일정을 우선 정렬
- 출발일 기준 D-Day 표시 (D-7 / D-DAY / D+1 형식)
- 체크리스트 진행률 막대 및 완료 수 표시
- 홈 화면 오늘의 업무: 오늘까지 기한인 미완료 업무와 기한 초과 업무 표시
- 오늘의 업무를 누르면 해당 여행 일정 상세로 이동
- 일정 복제: 일정 상세의 복제 버튼 → 내용 수정 → 저장
- 복제 시 기존 체크리스트 구성도 복사되며 완료 상태는 미완료로 초기화
- 복제 일정의 출발일 변경 시 체크리스트 기한도 날짜 차이만큼 자동 이동
- Room DB 2 → 3 마이그레이션 추가(기존 일정 보존)
- 시작 화면 3.0초 및 최종 TRAVELER 오케스트라+음성 시작음 반영
