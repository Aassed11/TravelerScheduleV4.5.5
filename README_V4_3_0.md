# TRAVELER Schedule V4.3.0

편의성 업데이트

1. 최근 일정 / 즐겨찾기 빠른 접근
   - 홈에 최근 본 일정 최대 3건 표시
   - 기존 중요 일정(즐겨찾기) 유지
2. 빠른 일정 추가
   - 홈/캘린더/일정/주소록/설정 및 일정 상세에서 + 버튼으로 새 일정 등록
3. 체크리스트 일괄 처리
   - 일정 상세에서 선택 모드 또는 길게 누르기로 여러 업무 선택
   - 완료 / 되돌리기 / 전체 선택 지원
4. 일정 복제 고도화
   - 새 출발일을 달력으로 선택
   - 체크리스트 포함 여부
   - 항공편/호텔 정보 포함 여부
   - 여행 기간 및 업무 기한 자동 이동
5. 홈 일정 필터
   - 오늘 / 이번주 / 이번달 / 출발예정 / 진행중 / 완료
6. 일정 상세 빠른 연락
   - 전화번호가 포함된 고객/가이드/랜드사 정보에 전화/문자 바로가기
7. 준비율 시각화
   - 일정 카드 및 상세에 체크리스트 완료율 표시
8. 출발 임박 자동 정렬
   - 진행중 → 가까운 출발 일정 → 기타 → 완료 일정 순으로 정리
9. 앱 잠금
   - 4자리 PIN
   - 지원 기기에서 지문/얼굴 인식
