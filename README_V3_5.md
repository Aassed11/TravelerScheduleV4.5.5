# TRAVELER Schedule V3.5

## 이번 버전 변경사항
- 설정 화면에 출발 알림 기간별 체크박스 추가
  - 출발 30일 전
  - 출발 14일 전
  - 출발 7일 전
  - 출발 3일 전
  - 출발 1일 전
- 각 항목은 개별 활성화/비활성화 가능
- 기본값은 5개 모두 활성화
- 설정값은 SharedPreferences에 저장되어 앱 재실행 후에도 유지
- 알림을 끄면 기존에 예약된 해당 D-day WorkManager 작업도 즉시 취소
- 알림을 다시 켜면 현재 저장된 여행 일정들에 대해 해당 D-day 알림을 다시 예약
- 항공권 발권/호텔 취소/잔금/여권 확인 등 직접 입력하는 주요 기한 알림은 별도로 유지
- versionCode 8 / versionName 3.5
